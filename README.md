A tiny deterministic program that writes a one-line weather forecast for the invented city of Snuzzleford — drizzle till nine, then sunshine — into entry.txt, to charm a bored commuter on the way to work.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
